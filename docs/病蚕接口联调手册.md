## 1 卡点：隧道没连上（这不是代码问题）

实测（2026-10-17）：

```
TCP 10.66.66.1:80        → TIMEOUT
Get-NetAdapter | ? InterfaceDescription -match 'WireGuard|Wintun'  → 空
本机 IPv4                → Radmin VPN 26.113.128.200/8、WLAN 10.201.117.31/17、其余 169.254.x
```

`10.66.66.1` 是 WireGuard 隧道**对端**地址，只有本机先加入该隧道才存在这条路由。
现在本机没有 WireGuard 虚拟网卡，所以任何 `http://10.66.66.1/...` 都必然超时 —— 与 App 代码无关。

**要做的事**：找后端要 WireGuard 配置文件（`.conf`），用 WireGuard 客户端导入并激活，然后：

```powershell
Test-Connection 10.66.66.1 -Count 2
curl.exe -s -H "Authorization: Bearer test" http://10.66.66.1/api/barns/barn01/diseased?status=pending -m 10
```

能返回 `{"ok":true,...}` 才说明隧道通了。

## 3 隧道通了以后：切到真实后端

1. **我的 → 后端接口**把地址改回 `http://10.66.66.1/api`（改地址会自动重启数据流）；
2. 点 **测试连接**；
3. 跑一遍交付单 §9 的 curl 清单（把 `barn01` 换成你要测的蚕房）：

```bash
BASE=http://10.66.66.1/api
H='Authorization: Bearer test'

curl -s -H "$H" "$BASE/barns/barn01/diseased?status=pending&limit=10"   # 期望 200，data:[]
curl -s -o /dev/null -w '%{http_code}\n' "$BASE/barns/barn01/diseased"   # 不带鉴权 → 401
curl -s -o /dev/null -w '%{http_code}\n' -H "$H" "$BASE/barns/barn01/diseased?status=bogus"  # → 400
curl -s -o /dev/null -w '%{http_code}\n' -H "$H" "$BASE/barns/barn01/diseased?limit=0"       # → 422
curl -s -H "$H" "$BASE/barns/barn01/clamp/jobs?status=all&limit=5"      # 期望 200
curl -s -H "$H" "$BASE/barns/barn01/patrol/status"                      # 期望 200
```

> 交付单 §9.1 已记录线上实测：`diseased_tray` 目前 0 行，所以列表返回 `data: []` **是正确行为**，
> 机械页会显示「暂无待裁定病蚕」。想看有数据的界面，用第 2 节的桩服务。

## 5 看到这些提示 = 什么问题

| 界面提示 | 实际原因 | 怎么办 |
|---|---|---|
| 请求超时：请确认已连上 WireGuard 隧道 | 隧道没连/路由不通 | 见第 1 节 |
| 网络不可达：请确认已连上 WireGuard 隧道与后端地址 | 同上，或地址写错/漏 `/api` | 先用手机浏览器打开 `/api/health` |
| 未授权：访问令牌为空或被拒绝 | 令牌没填 | 我的 → 后端接口填任意非空 |
| 查询状态参数不合法 | 代码 bug 或手改了 URL | 只允许 `pending/done/all` |
| 裁定参数不合法 | 同上 | 只允许 `yes/no` |
| 该病蚕记录不存在（可能已被其他端处理）| 404 | 正常，刷新列表即可 |
| 该记录已由他人裁定，请刷新列表 | 409 `already_decided` | 正常，看该条已有的 decision |
| 分页参数超出允许范围（limit 1~500）| 422 | 代码里 limit 写死了 50，正常不会出现 |
| 服务暂不可用（识别/机械模块未就绪）| 503 | 找后端确认服务状态 |
| 后端返回格式异常 | 信封不是 `{ok,data}` | 可能连到了别的服务/网关页面 |

## 6 要和后端确认的三件事

1. **蚕房编号**：App 里有 barn01~barn04，交付单只举了 `barn01`。其余三栋是否都有数据？没有的话切过去会是什么（空列表还是 404）？
2. **后台识别开关**：`/patrol/status` 现在 `enabled=false`，说明巡检没开，所以 `diseased_tray` 是 0 行。什么时候能开、开了之后多久出第一条？
3. **码垛机是否就位**：`placed` 要真为 `true` 必须有 B 的阶段回执（PLACED），否则永远「已下发，尚未放到位」。机械侧现在能不能跑？
